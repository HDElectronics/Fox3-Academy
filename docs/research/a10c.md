# A-10C II Tank Killer: what DCS shows the CAS pilot

Researched 2026-09-27 for the A-10C II CAS slice. Game level only (AGENTS.md rule 1): keys, HOTAS functions,
MFCD pages, HUD cues, radio flow and in-game numbers as the DCS player meets them. No weapon engineering.
Extends `docs/research/cas-jets.md` (section 0 JTAC flow, section 2 A-10C II: laser and LSS codes, LSS/LST
basics, digital 9-line, UTM waypoint entry, markpoints). Those facts are referenced, not repeated.

Confidence tags per fact:

- **verified (M p.N)**: ED *DCS A-10C II Tank Killer Flight Manual* (EN, 814 pages), printed page N
  (printed and PDF page numbers match). Manuals can lag the current build; nothing here was checked in game.
- **verified (T)**: text of ED's own A-10C II training missions (`Mods/aircraft/A-10C_2/Missions/Training`),
  read through a public Japanese localisation of the mission dictionaries [T]. Key names are in Latin in that
  text; the wording around them is a translation. Treat as ED source, second hand.
- **community (K)**: community exports of the DCS default input lists [K1][K2], or forum/search results.
- **not verified**: searched, no reliable source; do not show as fact.

## 1. Default keyboard bindings for the CAS HOTAS set

DCS names from the Controls menu (category HOTAS). The manual itself gives only one keyboard default
("SPI can be set by either TMS Forward Long or holding LCtrl + Up Arrow", M p.488); the rest come from the
input-list exports, cross-checked against the ED training missions where they name the key.

Short press = press and release; **Long = hold 1 s or more** (verified M p.107). In DCS a long press on a
keyboard key is simply holding the key.

| HOTAS function (DCS name) | Keyboard default | Confidence | Src |
|---|---|---|---|
| HOTAS TMS Forward / Aft / Left / Right | `LCtrl + Up` / `LCtrl + Down` / `LCtrl + Left` / `LCtrl + Right` | verified (M p.488 for Fwd; T for Fwd, Aft, Right) + community list | M, T, K1, K2 |
| HOTAS DMS Forward / Aft / Left / Right | `Home` / `End` / `Delete` / `PageDown` | verified (T, all four) + list | T, K1, K2 |
| HOTAS China Hat Forward / Aft | `V` / `C` (hold for Long) | verified (T) + list | T, K1, K2 |
| HOTAS Coolie Switch Up / Down / Left / Right | `U` / `J` / `H` / `K` | verified (T, all four) + list | T, K1, K2 |
| HOTAS Slew Up / Down / Left / Right (TDC, cursor, sensor slew) | `;` / `.` / `,` / `/` | verified (T) + list | T, K1, K2 |
| HOTAS Master Mode Control Button | `M` | verified (T) + list | T, K1, K2 |
| HOTAS Nosewheel Steering Button (laser fire in the air) | `Insert` | verified (T, PGM lesson) + list | T, K1, K2 |

| Jettison weapons | `LCtrl + W` | community list (A-10C) | K1 |

Notes:
- `Space` is also "continue" in every ED training mission prompt (T). Weapon release on `RAlt + Space` and
  gun on `Space` are from the A-10C (original) default list; that they carried over unchanged to the A-10C II
  is **community**, not verified.
- `Insert` is the Nosewheel Steering button; airborne it fires the laser (M p.621, T). The ED TGP training
  lesson (older text) calls the laser button the "pinky" button; the manual and the PGM lesson say NWS
  button. Use **NWS button / Insert**.

## 2. Sensor of Interest (SOI) and SPI

| Topic | Fact | Confidence | Src |
|---|---|---|---|
| What SOI is | Only one display is the SOI; HOTAS commands (slew, TMS, DMS, China Hat) act on it. Possible SOIs: TAD, TGP, HUD, HMCS, MAV, AIM-9. | verified (M p.107, p.483) | M |
| MFCD as SOI | A green "container" box around the inside of the MFCD. The other sensor MFCD shows **NOT SOI**. | verified (M p.484–485; T) | M, T |
| HUD / HMCS as SOI | An **asterisk** in the lower left of the HUD (or HMCS). No asterisk = not SOI. HUD is SOI at mission start. | verified (M p.486; T) | M, T |
| Set SOI | Coolie **Up Short** = HUD; **Down Short** = HMCS; **Left Long** = left MFCD; **Right Long** = right MFCD. Coolie Left/Right **Short** cycles that MFCD's pages. Coolie Down **Long** = DSMS quick-look; Up **Long** = MSG quick-look. | verified (M p.112, p.487) | M |
| Older text | The HOTAS training lesson (written for the A-10C) says Coolie Down Short swaps the MFCD pages. On the A-10C II it selects the HMCS. | verified (T) vs (M) | T, M |
| What SPI is | One shared 3D point for cueing weapons and sensors and for datalink. Default SPI = current steerpoint. SPI generator is shown lower left of the HUD. | verified (M p.487–488) | M |
| Set SPI | **TMS Forward Long** from the SOI (TGP crosshair, MAV LOS, HUD TDC, hooked TAD symbol, HMCS LOS). | verified (M p.488–490) | M |
| Reset SPI | **TMS Aft Long** = SPI back to steerpoint. | verified (M p.483, T) | M, T |
| Slave all to SPI | **China Hat Forward Long**: every sensor (TGP, MAV, HUD TDC) points at the SPI. | verified (M p.488, p.618) | M |
| TGP to steerpoint | **China Hat Aft Long** slaves the TGP to the current steerpoint (not the SPI). | verified (M p.112) + ED 2.5.6 changelog | M |
| HUD SPI in modes | NAV and CCRP: SPI = steerpoint. GUNS / CCIP: SPI = pipper line of sight to the ground. | verified (M p.489) | M |
| TAD SPI symbol | Three-step **"wedding cake"**; a Mini-SPI (one step less) for a datalinked flight member's SPI. | verified (M p.356, p.378) | M |

## 3. Targeting pod (Litening) on the MFCD

All **verified (M pp.381–402)** unless marked.

| Topic | Fact | Src |
|---|---|---|
| Power and modes | AHCP TGP switch ON. TGP page opens in **STBY** with "NOT TIMED OUT" for about 60 s. Then OSB 2 **A-G**, OSB 3 **STBY**, OSB 4 **A-A**. A-G starts boresighted 150 mils below the nose. | M p.382–389 |
| Video | Upper right: **CCD**, **WHOT**, **BHOT**. Boat Switch Center = CCD, Fwd = BHOT, Aft = WHOT. | M p.385, p.112, p.618 |
| FOV and zoom | Upper left: **WIDE** / **NARO** (China Hat Fwd Short toggles). Zoom 0Z–9Z with DMS Fwd/Aft. Four corner brackets in WIDE show the NARO area. | M p.384–395, p.618 |
| Track modes | Text next to the crosshair: **AREA** (scene stabilised), **POINT** (box on the object, follows movers), **INR-A** / **INR-P** when masked, **INR** (fixed geographic point). TMS Fwd Short toggles AREA/POINT; TMS Aft Short returns to INR. | M p.394–395, p.619 |
| Crosshair | Area crosshair; Point crosshair adds a centre box; IR-pointer and "both" reticles add end ticks. Crosshair flashes 1 Hz within 5° of masking; **M** next to the laser field when masked (laser cannot fire). | M p.394–396 |
| Laser status | **L** laser, **P** IR pointer, **B** both (TL/TP/TB with the AHCP laser switch in TRAIN). **Flashes 2 Hz while firing.** The HUD repeats it (no T prefix). | M p.392–394 |
| Range field | `L x.x` = laser range, `T x.x` = tracking without laser, `E x.x` = slewing estimate, in nm. | M p.393–394 |
| Designator select | OSB 7 **LSR / IR / BTH**, or DMS Right Short with TGP SOI ("laser mode toggle"). | M p.391; T |
| Laser fire rules | TGP ON, AHCP Laser ARM or TRAIN, airborne, code entered, not masked. LATCH OFF = hold NWS; LATCH ON = press to toggle. | M p.392, p.400 |
| Auto-lase | In an LGB profile: ON fires in the lase window, CONTINUOUS from release; both stop 4 s after computed impact. | M p.393 |
| Other fields | SA cue (small square: where the pod looks relative to the nose), yardstick, north arrow, AGL altitude, Zulu time, LL or MGRS of the crosshair plus elevation (CNTL OSB 7). | M p.385, p.396–399 |
| Codes | CNTL page: **L** (OSB 18) and **LSS** (OSB 17), 1111–1788, first digit 1, others 1–8; bad entry gives INPUT ERROR. Default 1688. | M p.400–401, p.621 |
| LSS text | FOV field reads **WSCH / NSCH**; crosshair spans the display with an open gate; **LSRCH** lower centre while searching; **DETECT** on a hit and the OSB 6 label changes **LSS → LST**; after 1 s **LTRACK** with a box on the spot; lost spot = **NO LSR** for 1 s, then LSRCH. HUD TGP diamond marks the LST. | M p.389–391 |
| LSS start / stop | Start: OSB 6 or DMS Right Long (M p.623); the HOTAS throttle table lists China Hat Aft Short with TGP SOI as "Toggle LSS" (M p.112). Stop: OSB 6, China Hat Aft Short, command a track, or select laser/IR. | M |
| Search range | "Usually within 20 miles" to find targets visually (ED training). | T (PGM) |
| Markpoint | TMS Right Short makes a markpoint at the crosshair (A first). | T |

Conflict to record: the manual's checklist gives **DMS Right Long = "Slave TGP to HMCS LOS"** (M p.749) and
the HMCS table uses DMS Right Long the same way, while the employment chapter says DMS Right Long starts LSS
(M p.623). **Not verified** which one the current build does with the TGP as SOI; teach OSB 6 for LSS.

## 4. TAD page (tactical awareness display)

| Topic | Fact | Confidence | Src |
|---|---|---|---|
| Ownship | Solid green plan-view aircraft, centre (CEN) or 27.5 % up from the bottom (DEP). DMS Right Short toggles CEN/DEP with TAD SOI. | verified (M p.357; T) | M, T |
| Scales | CEN: 5, 10, 20, 40, 80, 160 nm; DEP: 7.5, 15, 30, 60, 120, 240 nm (ownship to outer ring). DMS Fwd/Aft, or push the cursor to the top/bottom edge. | verified (M p.359–360; T) | M, T |
| Range rings | Outer ring = scale, inner ring = half; filled triangle tick points to magnetic north. DEP uses two 130° arcs. | verified (M p.356–357) | M |
| Cursor | Green cross, slewed when TAD is SOI. Hook: cursor over a symbol + **TMS Fwd Short** (active hook) or just rest on it (passive). Hooked symbol gets bearing/range/elevation text and a hook line (OWN, BULL or CURS). | verified (M p.356, p.365–367, p.616) | M |
| SPI and TGP | Wedding-cake SPI always somewhere on the TAD; green **diamond** = TGP line of sight. | verified (M p.356, p.358) | M |

Hook the triangle, TMS Fwd Long = SPI. | verified (M p.379–380) | M |
| Net | NET page OSB 10; "For best JTAC communications, set the NET ID to 01-01". | verified (M p.378) | M |
| Broadcast SPI | TMS Left Long; others see a Mini-SPI joined to you by a blue line. | verified (M p.378) | M |
| Hostiles | Hooking a hostile shows coordinates and unit type. Red hostile symbol shapes were not read from the figures. | verified (M p.381) / symbol art not verified | M |

## 5. HUD delivery modes and the gun

| Topic | Fact | Confidence | Src |
|---|---|---|---|
| Master modes | Master Mode Control Button (`M`) cycles **NAV → GUNS → CCIP → CCRP**; the mode name shows in the HUD centre. Hold it for air-to-air. | verified (M p.628, p.463) | M |
| Profile select | HUD SOI, **DMS Left/Right Short** cycles the DSMS weapon profiles on the HUD rotary; the profile name, selected stations and ARM/TRAIN/SAFE show lower left. | verified (M p.444, p.750; T) | M, T |
| CCIP bombs (MAN REL) | Pipper in a reticle with a range bar (clock = thousands of ft, clamped at 12000 ft); **PBIL** line; **DRC** (desired release cue) shows after flight path is −3° or lower; **MRS/MRC** = minimum release; **X** in the reticle = below minimum, invalid release. Put the pipper on the target and press release. | verified (M p.442–444, p.752) | M |
| CCIP consent (CR) | IFFCC TEST menu, CCIP CONSENT: **OFF** (manual), **3/9** or **5 MIL**. Pre-designate TTRN shows in the reticle. Put the pipper on the target, **hold** weapon release: ASL appears, a 5-mil **solution cue** runs down the ASL with a TTRN countdown; keep holding until the pipper passes through the cue (5 MIL) or the cue is inside the reticle (3/9); the bomb drops by itself. Letting go early cancels. X in the cue = too much steering error. | verified (M p.426, p.445–450, p.753) | M |
| CCRP | SPI is the aimpoint. Fly the PBRL/reticle onto the **ASL**; TTRN appears about 20 s out; about 5–6 s out the cue and TTRN slide down the ASL; hold release until the cue passes the reticle. LGBs allow 3/9 only. | verified (M p.455–459, p.672; T) | M, T |
| IAM (GBU-38) | Release cue runs round the IAM reticle; between max and min range carets the in-range field reads **MAN REL**; hold (do not tap) release or risk a hung store. | verified (M p.678–679; T) | M, T |
| Rockets | CCIP only in manual release; **RKT** and slant range under the rocket reticle; TOF numeric. ED lesson: roll in inside 4 nm, fire inside 2 nm. CCRP rockets (lofted) are less accurate. | verified (M p.451, p.640; T) | M, T |
| Gunsights | DMS Left/Right Short in GUNS cycles **CCIP Gun Reticle** (pipper, range bar, two moving-target ticks for 20 kt), **CCIP Gun Cross**, **4/8/12 reticle**, **4000 ft Gun Cross**. The Gun Cross also shows in CCIP. **CCIP INVALID** when target elevation is unknown or above you. | verified (M p.628–633; T) | M, T |
| Gun use | Trigger first stage = PAC (GUN/PAC switch ARM), second stage fires. Ammo shown as `CM/1150` in the HUD data block. Effective strafe 0.5–2 nm slant; tanks at 0.5–1 nm, from behind. | verified (M p.110, p.632–633; T) | M, T |
| Arming | AHCP: Master Arm ARM, GUN/PAC ARM (or GUNARM = no PAC), Laser ARM, TGP ON, JTRS (datalink) ON. | verified (M p.612–613) | M |

**Compared with ALR-56 style scopes in this app** (F-15C ALR-56C, F-16C ALR-56M, see `src/data/rwr.ts`):
- Same ED two-letter/number code family (`29`, `15`, `10`, `BB`, `SD`...), same "flashing circle = launch" idea.
  The A-10C adds `L` (laser warning), MWS `M` and `A` for Gepard/ZSU. **verified (M)**
- ALR-56C (FC3) uses signal strength for radius like the A-10C manual; ALR-56M puts lethal threats inward,
  like the A-10C training text. Which rule the A-10C II scope follows in the current build is **not verified**.
- The A-10C manual lists no hat, diamond or semicircle; the ED lesson shows them as on the ALR-56 scopes.
  Treat the modifiers as **verified (training text only)**.
- A-10C `M` can be an MWS plume detection (any missile, friend or foe, 10 s hold); on ALR-56 scopes `M` is an
  active radar missile seeker. **verified (M p.502)**; different meaning, teach it.
