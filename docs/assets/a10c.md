# A-10C II and CAS exterior art

Seven original exterior files extend the existing asset library. All geometry is authored for this
repository under its MIT licence, with no copied meshes, game extractions, image textures or weapon
internals. Dimensions of stores, fittings, pylons and hinge travel are artist approximations. The A-10
uses the requested app envelope: length 16.26 m and span 17.53 m. No gameplay constants are changed.

## Files and runtime mapping

| File | Runtime IDs | Visual representation |
|---|---|---|
| `a10c.glb` | `a10c` | Straight low wing with drooped tips, high twin nacelles, twin fins, closed bubble canopy, muzzle, gear pods and 11 empty pylons |
| `gbu12.glb` | `gbu12` | Paveway II exterior; tail fins extended |
| `agm65.glb` | `agm65d`, `agm65h`, `agm65l`, `agm65` | Shared Maverick exterior; variant-specific nose windows simplified |
| `apkws.glb` | `apkws` | LAU-131 carriage pod, seven shallow opening surfaces; never used as a flying rocket |
| `mk82.glb` | `mk82` | Low-drag bomb exterior |
| `cbu97.glb` | `cbu97` | Closed canister; no contents modelled |
| `tgp.glb` | `tgp` | Litening-family pod, opaque sensor windows |

The file registry's existing Vite glob bundles all seven. `JetMesh('a10c')` loads the GLB and retains
`getJetModel('a10c')` as its synchronous procedural fallback, just as the other aircraft do. There is no
asynchronous change to `getJetModel`'s shared-geometry API. The pod assets are available for carriage
visuals; this task does not add a loadout attachment renderer or change the CAS page.

`a10Rig.ts` binds `gear.nose/port/starboard`, `flap.port/starboard`, and
`deceleron.port/starboard.upper/lower`. Their geometry is local to each hinge. Clean gear geometry is
baked retracted; full `gear` reverses that pose and places the tyres at Y = -1.95 m. Flaps lower and
upper/lower decelerons open in opposite directions. All nine pivots are required before configured
states use the GLB. A partial or failed load preserves the complete procedural fallback. Gear doors,
canopy opening, aileron roll and a cockpit interior are not animated.

## Rebuild and inspect

```sh
python3 scripts/assets/rebuild_models.py --work .shots/a10c-rebuild --only a10c gbu12 agm65 apkws mk82 cbu97 tgp
python3 scripts/assets/source/a10c/review.py --models src/assets/models --out .shots/a10c-model-review
npx tsc --noEmit -p .
npx vitest run src/render
scripts/shot.sh '/#/hangar?ac=a10c' .shots/a10c-hangar.png 1440 900 8000
```

The new batch uses `scripts/assets/source/a10c/generate.py`, a deterministic standard-library Python GLB
writer that batches geometry by material and moving hinge. This is a deliberate alternative authoring
path: Blender 5.2.2 crashed at Metal initialization in the restricted session, and the Blender MCP call
was refused under the session's no-approval policy. These exports must not be described as Blender-tested.

The GLBs use metres, nose -Z, up +Y, right +X, with the aircraft centred laterally and longitudinally.
They can be opened with Blender's glTF importer. A separate optional helper can produce editable Blender
files in an unrestricted Blender process (not exercised in this session):

```sh
blender --background --threads 2 --python scripts/assets/source/a10c/blender_sources.py -- --review .shots/a10c-model-review
```

The CPU review renderer uses NumPy and the **actual exported GLB**, writes quarter/top/side/rear views,
a deployed configuration and a store contact sheet. These are geometry reviews, not browser screenshots
or proof of the final PBR lighting. `manifest.json` records byte counts, hashes, draw counts and caveats.
No third-party reference images are redistributed. Official DCS/USAF reference URLs are retained, but
image access was unavailable during this session; exact variant detail is not independently verified.

## Validation scope

Render tests cover all files, catalogue aliases, geometry bounds, 11 pylon labels, seven pod openings,
embedded resources, finite positions, mesh budgets, rig movement, full retraction, incomplete-rig fallback,
pre-load configuration and excluding the carriage pod from flying projectile visuals. The independent
GLB auditor checks geometry structure and bounds; CPU views inspect orientation and silhouette.

The requested headless hangar check must still be run where Chrome can launch and access the dev server.
This session's `scripts/shot.sh` attempt reported `operation not permitted` and produced no screenshot.
A full-checkout typecheck also encountered concurrent CAS lesson errors; those files belong to another
agent and were not changed by this asset task. Final check results are reported with delivery.
