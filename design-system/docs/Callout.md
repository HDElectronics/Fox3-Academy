# Callout

A boxed aside that marks how far the trainer's model is being trusted.

`kind` sets the title: `simplified` for something the trainer abstracts, `dcs` for how the game behaves,
`real` for the real aircraft, `note` for your own title. Accuracy about DCS is the product — say which
one you mean rather than blurring them.

```tsx
<Callout kind="simplified" body="Missile drag here is a speed-over-time curve tuned to DCS outcomes, not a drag table." />
```
