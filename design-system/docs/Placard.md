# Placard

A small uppercase stencilled label, as painted on a cockpit panel.

The kit's label primitive: letter-spaced mono in the muted panel ink. Pass `for` to render a `<label>`
bound to a control id. Every group, readout and selector already draws its own placard — reach for this
when labelling something custom.

```tsx
<Placard text="Scan volume" />
```
